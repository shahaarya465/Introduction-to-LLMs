# Introduction to Large Language Models

This collection of Jupyter notebooks provides a practical introduction to Natural Language Processing (NLP), Large Language Models (LLMs), retrieval systems, fine-tuning, and model evaluation.

## Practicals

| File | Description |
|---|---|
| `1-NLP.ipynb` | Introduces foundational NLP concepts, including text preprocessing, linguistic analysis, and text chunking. |
| `2-BPE_vs_WordPiece.ipynb` | Implements and compares the BPE and WordPiece subword tokenization algorithms. |
| `3-LSTM_using_pytorch.ipynb` | Builds and trains an LSTM sequence model using PyTorch for text sequence mapping. |
| `4-Trasnformer_from_scratch.ipynb` | Implements core Transformer components, including positional encoding, attention, and multi-head attention. |
| `5-Text_Generation_and_Semantic_Search.ipynb` | Explores text generation strategies such as greedy and beam search, along with semantic search. |
| `6-Model_Hub_API_Comparison.ipynb` | Compares inference behavior between closed-source and open-source models using APIs. |
| `7-Advanced_Prompting_Architectures.ipynb` | Demonstrates zero-shot, few-shot, chain-of-thought, and ReAct prompting techniques. |
| `8-End_to_End_RAG_Pipeline.ipynb` | Builds an end-to-end Retrieval-Augmented Generation pipeline with document loading, embeddings, and vector search. |
| `9-GraphRAG_Multi_Hop_Retrieval.ipynb` | Demonstrates graph-based retrieval and multi-hop reasoning using connected entities and relationships. |
| `10-PEFT_QLoRA_VRAM_Measurement.ipynb` | Applies PEFT and QLoRA fine-tuning while measuring memory and VRAM usage. |
| `11-Multi_Agent_VLM_Evaluation.ipynb` | Creates a multi-agent workflow for tool use and evaluates a Vision-Language Model. |
| `12-LLM_Evaluation_and_Auditing.ipynb` | Evaluates LLM outputs for hallucinations, toxicity, alignment, and responsible AI concerns. |
